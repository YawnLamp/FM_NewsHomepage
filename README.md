Goals Reached:
- The HTML and CSS came together pretty easily and quickly here. Kept the non-reset CSS desktop build to about 150 lines of code, which is much more efficient than my last few projects.
- The mobile build had a couple snags, that were easily remedied. The padding translation from desktop to mobile was a little wonky so I had to add some negative margin for alignment, there is likely a more responsive fix for this, but this works for where my level is.
- The second snag was an aspect related to why I picked this challenge, which is to add some interactive elements that are normally implemented with JS. I used bootstrap to add the dropdown menu for the header, which worked well, although it took me a minute to realize that the gap set on the header in the desktop build was pushing the dropdown way off screen, once that was altered the project was basically finished.
